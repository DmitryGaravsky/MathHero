# Settings and offline use

Open **Parent mode → Settings and Data**. Language can also be switched from
the app header. If a column report is open, first select Multiplication tables
to show its parent menu, then open Settings and Data. These settings apply to
the whole app.

| Setting | Behavior |
| --- | --- |
| Language | Spanish by default. Russian is available. Numbers and dates follow the selected locale. |
| Theme | System by default. Select Light or Dark to set a fixed appearance. |
| Animations | On by default. The app also respects the device's reduced-motion preference. |
| Sound | Off. MathHero is silent. |
| Multiplication daily goal | 5, 10 or 15 minutes, with 10 as the default. The goal is a suggestion and practice can end early. |
| Multiplication glossary | Expand the section to see Spanish terms and their Russian meanings for multiplication, factor, product and multiplication table. |

## Parent PIN

Change the PIN in Settings and Data after entering parent mode. If you forget
it, choose **Reset PIN** in the entry dialog, confirm the reset and enter
**1234**. Reset removes only the custom verifier. History, preferences and
saved practice remain available. The PIN confirms a local mode switch.

## Install and practice offline

1. Open [MathHero](https://dmitrygaravsky.github.io/MathHero/) online.
2. In Settings and Data, wait for the offline status to say that practice is
   ready. If setup fails, reconnect and use the retry action.
3. In Safari, use **Share → Add to Home Screen**. Launch from the icon to use
   the standalone app. Check offline readiness in the specific browser or
   Home Screen window you will use.

Both practice modules, results, language changes and backup tools are available offline
after setup. If the Home Screen app and Safari show different histories,
[transfer a backup](DATA_AND_BACKUP.md) between them.

## Apply an update

MathHero on the Home Screen is an installed web app. Updates download from
the MathHero website; there is no App Store update to install.

1. Connect to the internet and open MathHero from the Home Screen icon you
   normally use. If practice is open, choose Pause or Save and exit and wait
   for the save to finish.
2. Enter Parent mode and open Settings and Data. Keep the app open until its
   offline status reports that an update is ready. Offline readiness alone
   means the current version is cached; it does not mean a new update is waiting.
3. Close any MathHero tabs in Safari and any other MathHero windows on this
   device. The update waits for existing app windows to close.
4. Close the Home Screen app through the App Switcher. On an iPhone without
   a Home button, swipe up from the bottom and pause around the middle of
   the screen. On an iPhone with a Home button, double-click it. Find the
   MathHero preview and swipe it upward to close it. Simply returning to
   the Home Screen is not the same as closing the app. See
   [Apple's illustrated instructions](https://support.apple.com/en-us/109359).
5. Reopen MathHero from the same icon and explicitly resume saved practice.
   For the 1.2 update, the illustrated home now includes Column arithmetic.

The update keeps saved progress, preferences and the local PIN. You do not
need to remove and re-add the icon. Do not delete the app or clear Safari
website data as an update step: local learning history can be lost. Use
[Export](DATA_AND_BACKUP.md) to keep a copy outside the app.

### If the new module does not appear

Check that the device is online. Save practice, close all MathHero windows
and reopen from the same icon while online, then check the update status again.
An app that was left open can still be showing the previous version. If a
download fails, the previous complete app stays usable; reconnect and retry
offline setup if the app offers that action.

Safari and the Home Screen installation can have separate histories. Updating
Safari alone does not establish that the installed app has updated. Check in
the installation the child actually uses, and keep its existing data.
