# MathHero 1.2 physical-device checklist

Status — pending on iPhone and iPad. The
[1.1 device sign-off](DEVICE-ACCEPTANCE.md) covers the multiplication release.
See the [1.2 delivery record](DELIVERY-COLUMN-ARITHMETIC.md) for publication status.

Use Safari and the Home Screen installation at
[the MathHero Pages URL](https://dmitrygaravsky.github.io/MathHero/), where
1.2.0 was published on 17 November 2026. Record the iPhone and iPad models,
OS versions, installation mode and observed results. Export important history before any restore or
storage reset. Use a disposable profile or installation for backup tests.

| Check | Expected on each device | iPhone | iPad |
| --- | --- | --- | --- |
| Home and navigation | The counters and notebook cards are distinct and tappable. Multiplication and both column operations open within two actions. Check portrait and landscape. | Pending | Pending |
| Languages and appearance | Try Spanish and Russian and the System, Light and Dark themes. Switch back from parent mode. Navigation, digits, marks, focus and help remain readable without horizontal scrolling. | Pending | Pending |
| Addition | Start a three-digit addition. Enter digits from units leftward, select and replace a digit, erase, and toggle a carry one above the thousands cell. Check a correct answer and watch the short confirmation advance. | Pending | Pending |
| Subtraction | Start a three-digit subtraction. Toggle dots above lending digits. When a borrow through zero appears, dot the zero and check the answer. Use the on-screen controls in both orientations. | Pending | Pending |
| Error and help | Check an incorrect answer. The first place to revisit is clear and the draft remains visible. Open the worked help, close it, and explicitly correct the answer. | Pending | Pending |
| Separate drafts | Save a marked addition and subtraction with digits and a selected place. Switch between operations and enter and leave parent mode. Return to each saved draft and confirm the same exercise, digits and marks. | Pending | Pending |
| Timing and feedback | Background or pause during feedback and reopen. Resume explicitly. Confirm incorrect feedback waits and that saved correct feedback can continue with Next. | Pending | Pending |
| Parent view | Use the local PIN. Switch between modules and between addition and subtraction, then read the percentages and expand a session. Check that help and notes are visible in history. | Pending | Pending |
| Offline launch | Wait for offline readiness in the Home Screen installation. Save both marked drafts, close the app, enable airplane mode and reopen. Resume both drafts and complete a check while offline. | Pending | Pending |
| Upgrade from 1.1 | On an existing 1.1 installation, save a multiplication draft before updating. Keep two clients open while the update prepares, then close every MathHero tab and Home Screen window. Reopen, check preferences, PIN, history and rewards, and confirm the saved multiplication question and entry resume. | Pending | Pending |
| Backup | Export 1.2 from Settings and Data. Restore it to a disposable destination and verify both modules' history and drafts. If a 1.1 export is available, verify that restoring it keeps the destination's column sessions. | Pending | Pending |

For any failed or unavailable case, record what happened and how far the check
got. Share observed results with the coordinator for the delivery record.
Browser emulation and desktop loopback timings are separate evidence.
