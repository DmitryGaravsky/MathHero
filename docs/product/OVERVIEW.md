# Product overview

Product reference for MathHero 1.2.

MathHero helps children recall multiplication facts for factors 1–12 and
practice addition and subtraction with two three-digit numbers. The child
chooses a module from the illustrated home. Column exercises support familiar
paper notation with optional carry ones and borrow dots.

Parent mode offers multiplication diagnosis, targeted practice, achievements
and a progress map. Separate addition and subtraction reports show first-check
accuracy, independent solutions, recent errors, practice after a gap and
comparable active times.

The React PWA runs in a browser and can be installed from Safari on an iPhone
or iPad. The interface supports Spanish and Russian and follows the system
appearance by default. Learning history stays in the browser's local storage
container. After the app prepares its offline files, practice and review can
continue without a connection.
