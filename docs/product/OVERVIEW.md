# Product overview

Status — active product reference for MathHero 1.1.

MathHero helps children recall multiplication facts for factors 1–12 accurately
and with increasing ease. Child mode centers on daily practice and achievements.
Parent mode offers optional initial diagnosis, targeted practice and progress
evidence to help an adult decide what to revisit.

The React PWA runs in a browser and can be installed from Safari on an iPhone
or iPad. The interface supports Spanish and Russian and follows the system
appearance by default. Learning history stays in the browser's local storage
container. After the app prepares its offline files, practice and review can
continue without a connection.
