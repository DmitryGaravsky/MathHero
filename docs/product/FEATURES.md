# Implemented features

Product reference for MathHero 1.2.

| Area | Available in 1.2 |
| --- | --- |
| [Child mode](../user/CHILD_GUIDE.md) | Illustrated module cards, large numeric input, immediate feedback, and separate saved multiplication, addition and subtraction practice |
| [Parent mode](../user/PARENT_GUIDE.md) | Local PIN, module-specific reports and session history, shared settings and data |
| [Multiplication tables](../pedagogy/LEARNING_MODEL.md) | All 144 directed facts, shared evidence for 78 pairs, diagnosis, 12 × 12 map, adaptive and targeted practice, spaced review, mastery and rewards |
| [Column arithmetic](../pedagogy/COLUMN_ARITHMETIC.md) | Three-digit addition and subtraction, carry and borrow notes, optional worked help, first-check and independent evidence, and reviews after a gap |
| [Settings and offline use](../user/SETTINGS.md) | Spanish and Russian, system/light/dark themes, animations, daily goal, bilingual glossary, install and update status |
| [Data](../user/DATA_AND_BACKUP.md) | Local automatic saves, resumable drafts, versioned JSON export and validated replacement from a backup |
