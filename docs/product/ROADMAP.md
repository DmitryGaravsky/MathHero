# Scope and future ideas

Status — active scope statement for MathHero 1.1.

The current release covers multiplication for factors 1–12. See
[implemented features](FEATURES.md) and the [1.1 delivery record](../DELIVERY-1.1.md)
for release verification and publication status. Physical iPhone and iPad
acceptance is tracked in the [device checklist](../DEVICE-ACCEPTANCE.md).

The [original MVP proposal](../specification.txt) lists inverse division facts,
column multiplication, long division and mixed operations as future ideas.
They have no scheduled release. Accounts, child profiles, backend services,
cloud sync, telemetry, voice input and competitive play are outside 1.1 scope.
