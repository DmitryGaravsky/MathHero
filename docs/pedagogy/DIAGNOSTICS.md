# Initial diagnosis

Multiplication assessment reference for MathHero 1.2.

The optional baseline in Parent mode shuffles all 144 directed multiplication
facts and presents each once, in six parts of 24. A part boundary offers a
break. You can also pause mid-part and resume the saved question, draft or
feedback. The baseline records correctness and active answer time for each
direction. Feedback, breaks, hidden time and pauses are excluded from timing.
Reported speed uses correct answers.

Baseline errors and correct-but-slow answers influence starting difficulty.
A single observed direction cannot establish that the whole pair has been
checked. Once the pair has practice evidence, that evidence drives its
difficulty. Diagnosis contributes to baseline analytics and the map. Practice
contributes to Learned, Fluent, Retained, mastery and rewards.
See the [learning model](LEARNING_MODEL.md).
