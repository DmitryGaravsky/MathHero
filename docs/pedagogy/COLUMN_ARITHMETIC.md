# Column arithmetic practice and evidence

Column sessions use two three-digit operands. The six-example pilot covers
four addition groups (no carry, one carry, multiple carries below thousands
and a carry into thousands) and five subtraction groups (no borrow, one
borrow, multiple borrows, a borrow through zero and a zero result). The
practice starts independently and revisits recent difficulties with fresh
operand pairs. Six examples is a pilot session length. The checks and review
gaps below describe app behavior and observed performance.

## Results

First-check accuracy is correct first checks divided by examples with a
check. Each example contributes at most one first check. A correct first check
after opening help contributes to accuracy. An independent solution is correct
on the first check without opening help. Manual carry ones and borrow dots are
working notes and preserve independent credit. A successful retry counts as a
solution after correction. The help count includes an example if help opened
at any point, including after its last check.

The issued count covers the examples actually presented. An unchecked example
has no check. An explicit skip and an unresolved example left open or ended
early are separate outcomes. Either can have a wrong check. A correct check
counts as solved as soon as it commits, including during correct feedback.

## Recent errors and practice after a gap

The recent-error flag means at least two misses in the latest four first
checks with fresh operand pairs in the same group. The misses can occur on
the same day. A mismatched digit is an observable difference between the entry
and the expected result. The child's calculation order and the cause of the
error are unknown.

Two independent first checks with fresh pairs on different local days and in
different sessions provide support. A further independent first check on a
fresh pair after a real elapsed gap can confirm the result. The review is in a
different session and on a different local day. The initial gap is at least
24 hours since last practice for the group, and later reviews use 72 hours
while that evidence remains current. Educational norms would require separate
validation of the session length, recent-error threshold and review intervals.

A wrong first check clears current support and verification, including when
help was open before the first check. A helped correct answer earns no new
support. The history preserves prior attempts and the dated checks that
established earlier evidence.

## Active time

The timing section takes the latest 100 recorded checks in the operation and
includes only independent correct first checks. It reports a sample size and
median within each group defined by carry or borrow places and result length,
with borrowing through zero and a zero result distinguished where relevant.
Compare times within a group. A small sample describes only the exercises it
contains. Time plays no role in independence, reviews or rewards.

In history the time at a check is the cumulative answering time within that
example, including prior active answering before a retry. The session total
adds the latest time for each example once. It excludes pauses, background
time, feedback and time spent with the help panel open.
