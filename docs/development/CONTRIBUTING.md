# Contributing

Status — active contributor instructions for MathHero 1.1.

Read the [repository instructions](../../AGENTS.md), the
[active requirements](../product/REQUIREMENTS-1.1.md) and the
[architecture overview](../architecture/OVERVIEW.md). Use
[local setup](SETUP.md), follow the [code style](CODE_STYLE.md), and run the
[appropriate checks](TESTING.md) before review.

Keep changes within the multiplication trainer's documented scope. Include
a concise description of the changed behavior, the checks that ran and any
outstanding evidence. For migration work, include a native reproduction using
synthetic history. For visible changes, review real app captures in both themes
and both languages as applicable.

For the 1.1 release, the coordinator owns stage branches, PR review, release
integration and publication. The [delivery record](../DELIVERY-1.1.md) tracks
acceptance. See [build and release](RELEASE.md) for deployment details.
